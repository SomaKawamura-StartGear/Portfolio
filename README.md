# Portfolio

Kawamura Soma のポートフォリオサイトです。

## 技術スタック

- React
- TypeScript
- CSS
- Vite

## セクション構成

- **Header** - ナビゲーション
- **Profile** - 自己紹介
- **About** - 経歴・タイムライン
- **Projects** - 制作実績
- **Contact** - お問い合わせ
